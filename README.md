## How This Works

This registry is automatically maintained by a [GitHub Actions workflow](.github/workflows/auto-scanner.yml) that:

1. Searches GitHub for MCP server repositories
2. Pulls entries from the [Official MCP Registry](https://registry.modelcontextprotocol.io/)
3. Analyzes each with AI (GPT-4o-mini via [GitHub Models](https://docs.github.com/en/github-models))
4. Caches results to avoid re-analysis
5. Regenerates this README with ranked results

Runs every Sunday at 02:00 UTC. No manual curation, no PRs needed.
